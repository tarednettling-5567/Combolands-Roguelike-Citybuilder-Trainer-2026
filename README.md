## 🎮 About the Game

Combolands: Roguelike Citybuilder is an indie strategy roguelike and deckbuilder developed and published by Crux Games. It released on August 24, 2026, for Windows. Each run combines citybuilding, card-based building choices, procedural islands, guild combinations, and cascading spatial combos.

## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Combolands: Roguelike Citybuilder**. This trainer provides optional assistance for single-player runs by modifying core run resources, building availability, cooldowns, placement rules, progression, and combo scoring. Use the options selectively to experiment with guild synergies, test city layouts, or reduce the grind between runs.

**Target Audience:** Players who want to explore all seven guilds, test the game's 21 guild combinations, build experimental cities, practice spatial combo setups, or shorten progression during repeated runs.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## ⚡ Features (v1.0)

### 🎯 Gameplay

- **Unlimited Gold** — Prevents gold from decreasing during purchases, rerolls, dismissals, and other run activities that use gold.
- **Free Rerolls** — Removes the gold cost from building, quest, or other available reroll actions.
- **Infinite Potions** — Keeps map-manipulation potions available after use, allowing repeated experimentation with potion effects.
- **Reveal Building Options** — Improves access to available building choices and blueprints, making it easier to test different city layouts and combo chains.

### 📌 Building

- **Freeze Building Cooldowns** — Prevents triggered building abilities from entering or advancing through their normal cooldown period.
- **Unlimited Building Triggers** — Stops limited-use building triggers from being consumed during a run.
- **Expanded Placement Range** — Allows buildings to be placed beyond their normal placement restrictions where the current run permits placement.

### 📌 Scoring

- **Combo Score Multiplier** — Multiplies score and number-growth effects generated by building synergies and cascading combos.

### 📌 Progression

- **Instant Rank Progress** — Accelerates progress toward milestones, victories, and the game's increasingly challenging ranks.
- **Unlock Guilds and Councillors** — Provides access to guilds, guild combinations, and city councillors without waiting for their normal progression requirements.

## 📖 Detailed Feature Guide

### Movement & Exploration

Combolands is a turn-based citybuilding game rather than a character-movement game. Navigate the interface normally with the mouse and keyboard. The trainer does not alter camera movement or cursor controls.

### Tools & Inventory

The game's run inventory includes gold, buildings, blueprints, heirlooms, potions, upgrades, and councillor-related progression. Activate resource options only after the relevant item or resource is visible, then make a purchase or use the item to confirm the change.

### World & Environment

Every run begins on a procedurally generated island. Place buildings carefully to extension adjacency, range, terrain, cooldown, and removal effects. Expanded Placement Range is most useful when planning unusual layouts, while Unlimited Gold and Free Rerolls support testing different building pools and quest choices.

### Combat & Weapons

Combolands has no conventional real-time combat system. Its challenges are resolved through building placement, guild objectives, score growth, milestones, and victory conditions. The trainer therefore focuses on citybuilding, resources, cooldowns, map interaction, and progression rather than combat damage or health.
